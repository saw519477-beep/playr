Routes & endpoints

Use these routes with your deployed Moonflix Player base URL.

BASE URL
PLAYERMOVIE
/movie/{tmdbId}

Opens a movie using its TMDB numeric ID.

EXAMPLE/movie/550
PLAYERSERIES
/tv/{tmdbId}/S{season}/E{episode}

Opens a specific series episode. Season and episode numbers start at 1.

EXAMPLE/tv/1399/S1/E1
